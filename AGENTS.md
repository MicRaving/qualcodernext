# AGENTS.md — QualCoder v4 (rework)

Guidance for AI agents working in this repository.

## Repo layout

- `backend/` — FastAPI + SQLAlchemy (async, SQLite) API. Venv at `backend/.venv`.
  Commands: `backend/.venv/Scripts/python.exe -m pytest tests`,
  `-m ruff check src`, `-m mypy src`. Entry: `backend/src/qualcoder_api/main.py`
  (packaged entry `backend/run_packaged.py`; PyInstaller spec `qualcoder_backend.spec`).
- `frontend/` — React 19 + TypeScript + Vite 6 + Tauri 2.
  Commands: `npm test` (vitest), `npx playwright test` (e2e, single worker),
  `npx tsc --noEmit -p tsconfig.json`, `npx eslint src --max-warnings 0`.
  Tauri shell: `frontend/src-tauri` (release build via `npx --yes @tauri-apps/cli@2 build`
  from `src-tauri/`; the backend onedir lives in `src-tauri/resources/backend/`,
  copied there by `compile.ps1`).
- `compile.ps1` — full release build (PyInstaller onedir → resources → Tauri).

## UI design language — READ FIRST

`frontend/src/DESIGN.md` is the authoritative UI spec: layout slots
(ribbon / menu bar / left bar / center / right bar / status bar), button
variants and colors, icon sizes, typography, and the per-view registry.
Every screen must adhere to it. The orchestrator is
`frontend/src/components/shell/WorkspaceLayout.tsx`; views fill slots —
they never build their own bars.

## Workflow rules

- Verify before finishing: backend tests+ruff+mypy; frontend
  tsc+eslint+vitest+playwright e2e (start the run from a clean state:
  kill leftover `qualcoder*`/uvicorn/vite processes and delete
  `%TEMP%\qc-e2e` if a previous run locked it).
- Do not commit: `frontend/src-tauri/target/`, `frontend/src-tauri/resources/backend/`
  (regenerated by compile.ps1), `tests-e2e/.servers.json`, `tests-e2e/*.log`,
  `updater.key`, `*.qda` user data.
- Never edit user data under `~/.qualcoder/` except to restore the settings
  file after test runs (e2e wipes it; restore recent project + sync off).
- The user's real project for manual verification:
  `D:\Downloads\LSTeach2.0_BKUP_20260714_21.qda` (contains category/code id
  collisions — tree code must stay namespace-aware with a depth cap).
