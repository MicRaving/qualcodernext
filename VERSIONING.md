# Versioning (for agents)

Bugfixes bump `0.0.1` (e.g. `0.1.0` → `0.1.1`).
Only major new features justify a `0.1` bump (e.g. `0.1.x` → `0.2.0`).
`+1.0` releases are manually administered by the owner.

Do not surface this policy in `CHANGELOG.md` or in the GitHub release bodies —
it is an internal agent guideline. Keep `CHANGELOG.md` sections short
(one-line bullets) with the detail behind the **Full Changelog** compare link.
